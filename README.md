# New-TestResourcedGroup

### New-TestResourceGroup is an advanced PowerSHell function used to create Azure resource groups in the Central US Region.

### Features include parameter validation, custom tags, parameter sets, pipeline input, structured output, WHATIF and Confirm support, verbose feedback, bulk processing, and execution statistics.

# NWTC.ResourceGroups Module

### NWTC.ResourceGroups is a PowerShell module used to create and manage test Azure resource groups.

### The module includes New-TestResourceGroup for creating resource groups and Get-ResourceGroupSummary for displaying resource group names, locations, and tags.

### Current Module Version: 1.1.0
